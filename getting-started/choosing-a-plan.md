# Choosing a Plan

WebMCP Master offers four plans designed for different usage levels. All plans include access to the chat interface and site connections. Higher tiers unlock agents, scheduling, workspaces, and increased limits.

## When to Upgrade

### Free to Pro

Upgrade to Pro when you:
- Need more than 3 sites in your vault
- Want to use multiple sites in a single chat session
- Need to create agents for automated tasks
- Want to use your own API key (BYOK) to avoid credit costs
- Want a personal system prompt applied to all chats

### Pro to Harness

Upgrade to Harness when you:
- Need scheduled agents (cron-based automation)
- Want to trigger agents via incoming webhooks
- Need the tool execution monitor for debugging
- Require more than 10 sites or 3 agents

### Harness to Team

Upgrade to Team when you:
- Need to collaborate with other users in a shared workspace
- Want outgoing webhooks for integration with external systems
- Need unlimited agents and sites
- Require user groups and granular permission controls

## How to Upgrade

1. Go to **Billing** in the sidebar.
2. Under **Choose a Plan**, click **Upgrade** on the plan you want.
3. If upgrading for the first time, you will be prompted to add a payment method.
4. Confirm the upgrade. Billing is prorated — you only pay for the remaining days in the current billing cycle.
5. New credits and features are available immediately.

## How to Downgrade

1. Go to **Billing** > **Choose a Plan**.
2. Click **Downgrade** on a lower tier.
3. Confirm. The downgrade takes effect at the **end of your current billing cycle**.
4. Your current features remain active until then.
5. Remaining credits are preserved.

::: warning
When downgrading, features beyond the new tier's limits become inaccessible. For example, if you downgrade from Team to Pro, workspace access is suspended and agents beyond the Pro limit are deactivated.
:::

## Cancellation

To cancel your subscription entirely:

1. Go to **Billing** > **Manage Subscription**.
2. Click **Cancel Subscription**.
3. Review the consequences:
   - You will be downgraded to Free at the end of the billing period
   - Agents, scheduling, and webhooks will be disabled
   - Monthly credits will stop renewing
   - Workspace and user groups become inaccessible
   - Chat history is preserved but access may be limited
4. Confirm cancellation.

You can reactivate your subscription at any time before the period ends.
